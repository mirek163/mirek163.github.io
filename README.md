# mirek163.github.io

The root of the developer website of the Momenest Android app.

- `app-ads.txt` — authorises Google AdMob to sell the app's ad space
  (the IAB app-ads.txt standard; AdMob reads it at the root of the domain).
- `index.html` — forwards to the privacy policy and terms at
  https://mirek163.github.io/momenest-legal/.
